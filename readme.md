# Code With Abbas — Personal Portfolio

A sleek, responsive, and performance-driven developer portfolio built with modern HTML5, CSS3, and vanilla JavaScript. Features an interactive project archive, digital resume preview, and smooth theme switching.

## 🚀 Key Highlights

- **Fast & Lightweight:** Zero heavy frontend frameworks or render-blocking dependencies.
- **Dark / Light Theme:** Persistent theme toggling with zero flash of unstyled content (FOUC).
- **Responsive Architecture:** Fully optimized for mobile, tablet, and widescreen desktop displays.
- **Active Contact System:** Dynamic AJAX form submission via Formspree API.

## 🛠️ Built With

- **Frontend:** Semantic HTML5, Modern CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+)
- **Icons & Typography:** System UI fonts with hardware-accelerated CSS animations
- **Form Handling:** Formspree REST API

## 📂 Project Structure

```text
portfolio/
├── index.html        # Home & About Me
├── resume.html       # Full Resume View & PDF Download
├── portfolio.html    # Featured Projects Showcase
├── contact.html      # Contact Form & Direct Links
├── css/style.css     # Unified Design System
├── js/script.js      # Theme Toggle & Interactivity
└── assets/           # Project Thumbnails & Documents
└── Projects/         # All Projects' Source Codes
```
